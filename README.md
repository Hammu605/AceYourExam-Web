# AceYourExam Web (PWA)

Official Web Application for **AceYourExam** platform. Built for Apple iOS (iPhone/iPad/Mac), Android, and Desktop web browsers.

## 🚀 Features
- **Progressive Web App (PWA)**: Works as a native full-screen app on iOS via Safari "Add to Home Screen".
- **Live Firebase Integration**: Realtime sync with Firestore `tests`, `app_directory`, and `test_pricing_control`.
- **Examination Engine**:
  - Live Countdown Timer with automatic submission on timeout
  - Interactive Question Palette with status indicators (Answered, Marked for Review, Unattempted)
  - Bilingual support (English & Hindi)
  - Comprehensive Result Scorecard with Solutions and Analytics
- **Diamond & Lock System**: Integrated with Admin-X diamond and pricing lock configurations.

## 🛠️ Stack
- React 18
- Vite 6
- Tailwind CSS 3
- Firebase Modular SDK 11
- Lucide Icons & Canvas Confetti

## 📦 Deployment
Automated GitHub Actions workflow deploys production builds directly to GitHub Pages and Firebase Hosting.
